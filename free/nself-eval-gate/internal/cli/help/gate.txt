Check the eval gate for a given autonomy tier.

Fetches the gate status from the nself-eval-gate plugin and exits with:
  0 — tier is cleared (all required suites pass thresholds)
  1 — tier is blocked (one or more suites are below threshold or have no runs)
  2 — invalid tier name provided
  3 — precondition not met (BGE-M3 or AI gateway unavailable; NOT a regression)

The supervised tier always exits 0 (enforcement disabled by design).

Valid tiers: supervised, semi-auto, full-auto

Examples:
  nself ci eval gate --tier supervised
  nself ci eval gate --tier semi-auto
  nself ci eval gate --tier full-auto

Usage:
  nself ci eval gate [flags]

Flags:
      --eval-url string         nself-eval-gate plugin base URL (default "http://localhost:3770")
  -h, --help                    help for gate
      --source-account string   Source account ID header value (default "primary")
      --tier string             Autonomy tier to check (required): supervised|semi-auto|full-auto

Global Flags:
      --json                      Machine-readable output: one JSON document on stdout (see JSON-Output)
      --no-deprecation-warnings   Suppress deprecation warnings (for scripted use)
      --no-monorepo               Disable automatic monorepo backend detection
