# family-wikitree (PLANNED)

WikiTree → nFamily migration helper. Status: `planned` — scaffold only, no implementation.

WikiTree is a free public collaborative genealogy wiki with a REST API (https://www.wikitree.com/wiki/Help:API_Documentation). No OAuth required for public data; OAuth required for private profiles.

Plugin follows the `family-*` helper pattern (core + helper-importer). Writes to `np_family_*` tables in the `family` plugin.

Port: 3512. Category: social. Tier: pro.
